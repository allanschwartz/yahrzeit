# -----------------------------------------------------------------------------
# CBS Yahrzeit Wall Appliance Installer
# -----------------------------------------------------------------------------
#
# Purpose:
#   Install the CBS Yahrzeit Wall PHP application on a fresh Ubuntu/Debian
#   appliance.
#
# Target platform:
#   - Intel NUC or similar x86_64 machine
#   - Fresh Ubuntu Server LTS installation
#   - Wired Ethernet
#   - Apache + PHP
#   - Application served at:
#
#         http://<appliance-ip>/yahrzeit/
#
# Expected install model:
#   This script is intended to be copied or curled onto the appliance and run
#   locally.  It installs operating-system packages, clones or updates only the
#   yahrzeit_site-v3 subdirectory using Git sparse checkout, configures Apache
#   to serve the site, runs syntax checks, and installs the managed cron
#   schedule.
#
#   It does not transmit commands to the physical LED controller.
#   It does not modify memorial CSV data.
#   During an update it remembers the previously recorded controller address
#   and preserves data/minhag.ini and data/yahrzeits-rev4.csv. It resets
#   deployed code to the selected remote branch, restores the live data, and
#   asks whether to keep or replace the remembered controller address. Do not
#   make source code edits in the appliance checkout.
#
# One-time use from a fresh appliance:
#
#   curl -fsSL -o /tmp/install-yahrzeit-appliance.sh \
#     https://raw.githubusercontent.com/allanschwartz/yahrzeit/master/yahrzeit_site-v3/bin/install-yahrzeit-appliance.sh
#
#   less /tmp/install-yahrzeit-appliance.sh
#   chmod +x /tmp/install-yahrzeit-appliance.sh
#   /tmp/install-yahrzeit-appliance.sh
#
# Recommended preconditions:
#   1. Install Ubuntu Server LTS.
#   2. Enable OpenSSH during Ubuntu installation.
#   3. Log in as the appliance administrator user.
#   4. Confirm network access:
#
#        hostname
#        hostname -I
#        ping -c 3 github.com
#
# What this installer sets up:
#   - git, using sparse checkout for yahrzeit_site-v3
#   - Apache
#   - a stable local Apache ServerName, avoiding DNS/address warning AH00558
#   - PHP CLI and Apache PHP support
#   - netcat for controller communication
#   - coreutils timeout support
#   - OpenSSH server enabled and started
#   - /var/www/html/yahrzeit symlink to the checked-out application
#   - PHP PCRE JIT disabled, to avoid executable-memory warnings on hardened
#     server environments
#   - local syntax and audit checks
#   - policy-derived cron entries owned by the appliance administrator account
#   - three months of compressed weekly scheduler logs under data/
#   - controller address requested interactively and stored in the application
#   - a narrow Apache systemd exception allowing writes to the application
#     data directory and access to the cron helper's sudoers authorization
#
# Repository:
#   https://github.com/allanschwartz/yahrzeit
#
# Application directory:
#   ~/src/yahrzeit/yahrzeit_site-v3
#
# Apache URL path:
#   /yahrzeit/
#
# After install:
#   1. Open:
#
#        http://<appliance-ip>/yahrzeit/
#
#   2. Run non-transmitting tests:
#
#        cd ~/src/yahrzeit/yahrzeit_site-v3
#        bin/yahrzeit --audit
#        bin/yahrzeit --dry-run
#
#   3. Confirm bin/yahrzeit-controller.conf before live testing.
#
#   4. Review the managed cron block printed by the installer. Save the Minhag
#      page, or run sudo bin/fix-up-crontab, whenever the schedule changes.
#
#   5. Review scheduled-operation history when needed:
#
#        tail -100 data/automation.log
#        ls -lh data/automation.log*
#
# Notes:
#   - It is safe to rerun; it should update the repo and refresh the Apache
#     symlink.
#   - For production, the appliance should have a stable address, either by
#     router DHCP reservation or site-local Ubuntu network configuration such
#     as /etc/netplan/*.yaml.
#   - The production password should be changed before installation at the
#     customer site.
#
# -----------------------------------------------------------------------------
